## Overview

This project is linked to the PhD work being conducted by Amey Gupta. It explores the determination of a heterogeneous battery coefficient, or a method to account for thermal heterogeneity within off-the-shelf battery models along all length scales. This work was motivated by the need for accurate performance predictions and the large amount of heat generated in high-power applications like motorsports and eVTOLs, leading to poor model responses.

This project, alongside its main objective, aims to determine whether parametrising a battery within 'perfect' thermal control leads to inaccurate results and if instead the process should be conducted in a thermal condition mirroring its use case. It also aims to construct a standardised Reference Performance test procedure to allow for traceability across laboratories and universities.
